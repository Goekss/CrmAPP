# CrmAPP

Dies ist eine CRM-Anwendung, die mit **ASP.NET Web APP 4.7.2** entwickelt wurde.  
Das Projekt wurde im Rahmen meiner Vorbereitung für **IHK** sowie für **unternehmensbezogene Praxiszwecke** umgesetzt.

Die Anwendung stellt eine **RESTful API** bereit, über die Daten an eine **React-basierte Frontend-Anwendung** übertragen werden können.

---

## Verwendete Technologien
- ASP.NET Web APP 4.7.2  
- Entity Framework 6  
- Microsoft SQL Server  
- Bootstrap (Frontend-Unterstützung)  
- OpenWeatherMap API
- für React (crud) von Crm APP

---

## API Endpunkte (Beispiele)

- `GET /api/kunden`  
  → Liefert Kundendaten aus dem CRM-System

- `GET /api/kunden/personal`  
  → Gibt Personalinformationen zurück (z. B. Name, Abteilung, Kontakt)

- `GET /api/projekte`  
  → Liefert Projektinformationen inklusive Kunden‑ und Mitarbeiterzuordnung

- `GET /api/kunden/weather/{stadt}`  
  → Ruft Wetterdaten über einen externen API‑Dienst (OpenWeatherMap) ab

## Projektziel

Ziel dieses Projekts ist es, die **Entwicklung von REST APIs** zu erlernen und eine **saubere Schnittstelle zwischen Backend (ASP.NET Web API)** und **Frontend (React.js)** bereitzustellen.

Das Projekt zeigt:
- Strukturierte API-Entwicklung  
- Datenbereitstellung für moderne Frontend-Technologien  
- Praxisnahe Umsetzung für Unternehmensanwendungen (CRM)
